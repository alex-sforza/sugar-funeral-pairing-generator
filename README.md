# Sugar Funeral — Pairing Generator

Готовый веб-генератор **«Эстетика пейринга»** для двух персонажей: анкета → динамика отношений → подходящая песня Sugar Funeral → фанатские отзывы и желания → готовый HTML-код эстетики.

## Продакшен-структура

- `index.html` — короткая точка входа, перенаправляющая на основной генератор.
- `index-final.html` — основной интерфейс и механика генератора.
- `samply-loader.js` — подключает каталог Samply и подставляет плееры/ссылки для доступных треков.
- `data/samply-links.json` — рабочая база ссылок и embed-кодов Samply.

Вся остальная логика подбора песен, анкеты, динамик, отзывов и итоговой эстетики находится в основном HTML-файле, поэтому отдельные старые тестовые модули и промежуточные базы здесь не нужны.

## Песни

Генератор работает с каталогом Sugar Funeral, встроенным в `index-final.html`. При наличии записи в `data/samply-links.json` выбранная песня получает настоящий Samply-плеер и ссылку на страницу трека.

## Результат

Генератор создаёт:

- шапку пейринга с именами и фотографиями по URL;
- тип и динамику отношений;
- цитату, связанную с выбранной песней;
- основную песню с Samply-плеером, если она подключена;
- скрытый под спойлером TOP-5 дополнительных песен;
- три фанатских отзыва — два о персонажах и один о том, насколько им подходит песня;
- четыре фандомных желания «Мы бы хотели это увидеть в каноне»;
- HTML-код готовой эстетики для копирования и вставки на форум.

## Публикация

Основная страница GitHub Pages использует `index.html` и автоматически открывает `index-final.html`.
