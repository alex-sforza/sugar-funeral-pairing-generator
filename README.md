# Sugar Funeral — Pairing Generator

База данных для генератора **«Ваши отношения, как песня Sugar Funeral»**.

## База песен

`data/sugar-funeral-songs.json` содержит 69 треков из предоставленного файла с текстами Sugar Funeral. Для каждого трека зафиксированы альбом, название, основной тип пейринга, дополнительные архетипы динамики, темы/триггеры и короткая цитата для итоговой карточки.

Полные тексты песен в репозиторий не копируются: хранится аналитический слой и короткие цитаты.

## Архитектура генератора

Следующий слой — анкета двух персонажей. Ответы переводятся в признаки отношений и сопоставляются с `pairing_types` и `themes`. После выбора песни генератор создаёт название пейринга, описание динамики, четыре фанатских отзыва и пять сообщений «а давайте такой эпизод…». Выбранный трек затем отображается как виниловая пластинка с внешней ссылкой на аудио.

## Источник

Анализ основан на пользовательском файле `Песни Sugar Funeral.docx`, загруженном в проект. Типы пейрингов и теги — аналитический слой для механики генератора.
